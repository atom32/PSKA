## Completed

- PSKA is capable as a RAG system and has moved beyond PoC into a Phase 1 MVP baseline.
- Multi-tenant and multi-KB foundations are implemented and have passed browser validation.
- Hybrid retrieval is available with BM25 plus BGE-M3 embedding.
- PDF and structured table QA work for Phase 1 factual questions, including the Hikvision annual report KB acceptance set.
- Evidence Scoring, Evidence Validation, Citation Selection, and Answer Pipeline audit are in place.
- Architecture Contract, Phase 1 exit criteria, ADRs, and RFC-0002 are documented.
- Embedding backfill/job control exists on the backend.
- PSKA no longer owns direct generation API keys; generation is routed through the configured agentic service.
- Digest scheduling is disabled by default and no longer pulls the project off the core QA path automatically.

- Graph + PDF joint reasoning is planned for Phase 2, not complete.

- Embedding process control has backend support; full product UI control is still pending.
